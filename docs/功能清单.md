# Escucha 功能清单（2026-10-27 定稿；状态见下）

## 定位
不会当地语言的人在国外办事的对话帮手。第一卖点：同时说、同时听——朗读时麦克风不关，对方插话照样翻。

## 功能（按开发顺序）
1. 同时说同时听：浏览器回声消除；对方开口时朗读自动变小声；"朗读到一半对方插话"测试（需 iPhone 实测）。
2. 对坐模式：手机平放，下半屏朝自己（中文），上半屏倒转 180° 朝对方（对方语言），两边同时更新。
3. 场合：顶部按钮 日常/看医生/学校/银行/政府办事，默认日常，可中途切换；AI 听几句自动判断并提示，可改。按场合用词，办事术语附中文解释。
4. 已知信息小清单：整场对话持续记录已说清的信息（时间、地点、资料、费用、联系人…），每句更新；可在屏幕上小显示。
5. 建议回答：对方每说完一句，结合整场对话给 2 条回答；时间/地点/资料等缺项时加第 3 条追问；已说清的不再问。点一下填进打字框，可改后发送并朗读。
6. 结束前提醒：按场合列出必问项，结束对话或对方说再见时，提示整场都没提到的重要问题，附现成外语问句，点一下读出。
7. 聊完出纪要：中文总结、待办（可加日历）、关键词，来自小清单。
8. 打字输入：不方便说话或不能说话时打字，翻译后读给对方，打字不怕识别错。
9. 两个朗读开关（⚙︎）："朗读我的话给对方"默认开；"朗读对方的话给我"默认关、音量小。麦克风始终在听。两开 = 双向语音（盲人可用）；两关 = 纯字幕（聋人可用）。iPhone 耳机时声音只能走一个出口，需实测。
10. 无障碍：VoiceOver 读屏标签、状态提示音、打开即开始听。
11. 任意两种语言：顶部右侧语言按钮（显示如"中⇄西"）选"我的语言"和"对方的语言"，可一键互换，默认中文/西语，记在手机上。

## 待定
- 扫码让对方用自己手机加入同一场对话（借鉴 metcha）。

## 模型
比赛版：Meta Muse Voice Transcribe（识别、说话人区分）+ Muse Spark 1.3（翻译、建议、清单、纪要）；朗读用 Soniox（Meta 无语音合成）。Meta 额度到前先用 Soniox + NewAPI。

## 不做
离线模式（必须联网，介绍里写明是取舍）；音频不保存（写进隐私说明）。

- ✅ v9 每个模型都有备用（未上线）：
  - 打字翻译：`groq-qwen-27b`（2 秒）→ `groq-gpt-120b`（2 秒）→ `gpt-6-luna`（reasoning_effort=none，3 秒）→ `local-llm`（5 秒，最后手段）。最坏情况共 12 秒。
  - 建议回答 / 已知信息清单 / "还没问"翻译：同一条链，超时 3 / 3 / 4 / 8 秒。
  - 纪要：Meta `muse-spark-1.3`（15 秒）→ `gpt-6-luna`（20 秒）→ `groq-qwen-27b`（10 秒）→ `groq-gpt-120b`（15 秒）。
  - 为什么这个顺序：groq-gpt-120b 实测约 0.5 秒、8/8 译对；local-llm 虽然 0.36 秒，但会把剂量句译错，所以只在最后用，并且冷却重排时也永远排最后。
  - 触发条件：出错、429 限流、5xx、超时、返回空、不是合法 JSON。刚失败的模型冷却 20 秒（`LLM_COOLDOWN_S`）直接走下一个，不每句都白等；日志写明由谁回答。
  - Groq 的两个模型共用一个账号额度：只要其中一个 429，另一个正常就直接用另一个；两个都 429，整个 Groq 一起冷却 20 秒，直接走 luna。
  - 可用环境变量改：`LLM_TRANSLATE_FALLBACK` / `LLM_FAST_FALLBACK` / `LLM_SUMMARY_FALLBACK`（逗号分隔备用链）；`LLM_TRANSLATE_TIMEOUTS` / `LLM_FAST_TIMEOUTS` / `LLM_SUMMARY_TIMEOUTS`（按链上顺序的超时秒数，如 `2,2,3,5`）。网关里没有 gpt-6.1-terra，所以用 gpt-6-luna。
  - 打字翻译提示词加了"对医生、老师、银行/政府窗口用正式称呼（usted）"，并要求只翻译不回答问题。
  - 说话人区分（Meta）挂了：字幕照常，只是没有标签（已有测试）。
  - Soniox（识别/翻译/朗读，没有别的服务商可换）：服务器侧掉线自动重连最多 6 次并提示"识别会话重连中…"；浏览器断线自动重连最多 6 次（状态栏提示"连接断了，正在自动重连…"），字幕编号和说话人时间轴接着走；全失败才提示"连不上识别服务，请检查网络后重新点开始"；Soniox 报错（余额不足等）显示具体原因；朗读失败先自动重试一次。
